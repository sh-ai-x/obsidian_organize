# add_wiki — topic-note frontmatter

The topic note is the **durable entry point** for a topic. This document
pins its frontmatter so `remove_wiki` can identify and retire it.

## File path

```
<vault>/topics/<topic>.md
```

- Directory `topics/` is created on first use.
- `<topic>` matches the slug used by `research`.

## Frontmatter

```yaml
---
topic: <topic>              # string — slug, matches _research/<topic>.md
created: <ISO-8601>         # string — first promotion time
updated: <ISO-8601>         # string — last edit
tags:
  - topic/<topic>           # list — at least one entry; tags inherit from staged file if present
sources:
  - <url-or-path>           # list — copied from staged file's sources[]
status: active              # one of: active | retired
retired_at: <ISO-8601>      # optional — set by remove_wiki
retired_to: <archive-path>  # optional — set by remove_wiki
---
```

`status` lifecycle:

| Value | Set by | Meaning |
|---|---|---|
| `active` | `add_wiki` | Topic note is live. |
| `retired` | `remove_wiki` | Topic was removed; archived metadata is in `retired_to`. |

## Body

```markdown
## Summary

<auto-generated from the staged file's ## Notes section>

## Sources

- <url-or-path> — <one-line caption>

## Related

- [[<other-topic>]]
```

## Worked example

```markdown
---
topic: hermes-protocol
created: 2026-09-05T10:30:00Z
updated: 2026-09-05T10:30:00Z
tags:
  - topic/hermes-protocol
sources:
  - https://example.com/hermes-spec
  - ~/Documents/notes/hermes-draft.md
status: active
---

## Summary

Hermes uses length-prefixed frames with a 4-byte big-endian header. The
protocol supports both text and binary payloads.

## Sources

- https://example.com/hermes-spec — Hermes wire-protocol specification, section 4
- ~/Documents/notes/hermes-draft.md — Internal draft from 2026-08-12

## Related

- [[wire-protocols]]
```
